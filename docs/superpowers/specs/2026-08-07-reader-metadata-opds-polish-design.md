# YMReader 阅读、刮削与 OPDS 收尾设计

## 目标

在不改变现有 Work 统一模型和原项目其他功能的前提下，完成四项收尾：

1. 中文刮削优先得到中文标题、简介和标签；本轮不配置 NAS 代理。
2. 元数据刮削进度与结果列表正确显示 Work 封面。
3. Web 阅读器下栏重新布局，提供明确可点击的“上一话 / 目录 / 下一话”和独立“连续阅读”开关。
4. OPDS 中由一个文件夹内多个 CBZ 组成的作品可以进入目录并获取每个真实 CBZ，不再出现空白。

## 元数据策略

- `zh` 模式按中文字段完整度、标题相关度和来源偏好综合排序，Bangumi 优先但网络失败不阻塞其他来源。
- MangaDex 支持 `zh-hans`、`zh-hant`、`zh-cn`、`zh-tw`、`zh-hk` 与 `altTitles`。
- 修复 AniList GraphQL 语法；Kitsu 不再把“中文偏好”错误映射为日文标题。
- MangaUpdates 仍可作为英文兜底，但不能在已有高相关中文结果时排在前面。
- 自动应用继续使用单个候选，避免本轮引入高风险的跨来源字段写入；候选排序保证中文结果优先。

## 刮削进度封面

- ProgressItem 明确携带 `entityType`、`entityId`、`representativeComicId` 和 `coverUrl`。
- Work 优先使用后端返回的 Work 封面；缺失时使用代表 Comic 缩略图。
- Comic 使用 Comic 缩略图。
- 加载失败显示统一占位图，不显示浏览器裂图。

## Web 阅读器

- 下栏分为三层职责：页进度、章节导航、阅读模式。
- 章节导航并入下栏，不再使用会被下栏遮挡的独立 `bottom-20 z-50` 浮条。
- 明确显示：
  - `上一话`
  - `目录 · 当前/总数`
  - `下一话`
- 目录抽屉打开后自动定位当前话。
- “长条”仅控制当前话的纵向图片布局。
- “连续阅读”是独立开关；开启后长条模式在当前话末尾加载并显示下一话，继续向下时切换阅读上下文和进度记录。
- 非长条模式保持原有边界跳转，不自动拼接。

## OPDS

- Work 导航条目与 Acquisition 条目分开。
- 多 CBZ Work：作品入口为导航 feed，feed 内每个 Unit 提供其真实 CBZ acquisition link。
- 整体 ZIP/CBZ Work：作品入口直接指向唯一真实归档文件。
- 所有链接使用当前真实 Comic ID，不使用 Work ID 代替 Comic ID。
- 保持 Range、HEAD、认证和封面接口兼容。

## 验证

- Go 单元/处理器测试覆盖元数据排序、语言字段、OPDS 多 CBZ feed 与 acquisition。
- 前端静态测试覆盖 Work 封面 URL、下栏按钮和连续阅读状态转换。
- 构建后在 `17680` 使用真实漫画验证：
  - 中文搜索结果顺序；
  - 刮削进度封面；
  - 上下话、目录、连续阅读；
  - OPDS 多 CBZ 作品。
