# 阅读器默认设置与导航修复设计

## 目标

修复定制 Android 客户端中已确认的阅读流程问题，同时让每个漫画库拥有独立的阅读默认设置，并恢复作品详情页的两种目录展示方式。

## 已确认问题与方案

1. **阅读器返回栈**
   - 阅读器返回使用 `pop` 保留真实进入来源。
   - 从作品详情进入时返回详情，再返回首页；从首页继续阅读时直接返回首页。
   - 不再用 `go` 强制重建详情路由。

2. **跨话页码继承**
   - 上一话/下一话切换时目标话默认使用 `startPage`，映射为目标话相对第 1 页。
   - 路由参数变化时强制重建阅读器页面控制器和阅读活动跟踪器，禁止沿用旧话的 `_currentPage`。

3. **详情页目录**
   - 保留文字列表模式。
   - 增加封面网格模式。
   - 章节封面优先使用 `WorkUnit.coverUrl`，没有时使用该话缩略图/首图，最后才回退到作品封面。
   - 模式只保存在客户端页面状态，不影响服务端数据。

4. **首页收藏按钮**
   - 移除 WorkCard 首页网格和列表上的收藏按钮。
   - 详情页和收藏页面保留收藏功能。

5. **漫画库默认阅读设置**
   - 设置页新增每个漫画库的默认阅读模式配置。
   - 优先级：作品设置 > 漫画库设置 > 全局设置 > 内置默认值。
   - 作品已有设置不会被漫画库默认值覆盖。
   - 设置保存在本地 SharedPreferences。

6. **连续阅读**
   - 增加作品级连续阅读开关。
   - 长条模式下跨 WorkUnit 自动追加下一话。
   - 单页/双页模式到当前话末尾后自动进入下一话。
   - 切换话数时持续更新作品级话数和页数进度。
   - 关闭连续阅读时维持当前话边界。

7. **版本显示**
   - 设置页不再显示硬编码的旧版本号，读取应用实际 package version。

## 非目标

- 不修改 NAS 漫画文件、书库、数据库或容器。
- 不改服务端 Work 数据模型。
- 不恢复合集或按文件夹收起功能。
