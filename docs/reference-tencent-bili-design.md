# 腾讯动漫 vs 哔哩哔哩漫画：设计语言量取

样本：腾讯动漫 9 张、哔哩哔哩漫画 10 张实机截图（1200×2664，435dpi ≈ 441×980dp，dp = px ÷ 2.72），并用两版 APK 的 `resources.arsc` 颜色 / 尺寸 token 交叉核对。截图时间 2026-11-03。

---

## 0. 一句话

- **腾讯动漫**：白纸黑字的"目录型工具"。单一橙色 #FF613E 承担所有强调，字号偏小、行高偏紧、信息密度优先；面板与内容同底色，靠分栏和字重分层。详情页会为 IP 做米色烫金皮肤。
- **哔哩哔哩漫画**：封面优先的"杂志型阅读器"。黑字 + 品牌粉 #FB7299 + 功能蓝 #32AAFF 三色分工，字号大一号、圆角大一号；阅读工具层恒为深色悬浮卡，与画面明确分层。

## 2. 字体与字号

两家都用系统 CJK 无衬线（思源黑体/Noto Sans CJK），不靠字体家族区分，靠字号、字重、颜色。

### 腾讯动漫（小一号、密）

| 角色 | 实测/估算 |
|---|---|
| 首页频道 tab（选中） | 约 20sp 加粗；未选 15–16sp 灰 |
| 分区标题（精品·企鹅娘打滚推荐） | 约 18sp 加粗 |
| 网格作品名 | 约 15sp |
| 网格标签、日期、点赞 | 约 12sp |
| 详情大标题 | 约 22–24sp 加粗，棕色 |
| 详情简介 | 约 14sp / 行高 1.5 |
| 设置行标签 | 实测字高 10.3dp ≈ 12sp |
| 目录头（共681话） | 实测 ≈ 11.5sp |

数字（章节号、点赞、评分）用等宽数字，`1 - 01` 两段固定宽度对齐，扫读时列不会跳。

## 3. 形状、尺寸与栅格

### 腾讯动漫

- 顶栏 **52dp**（`comic_reader_toolbar_height`、`chapter_topic_action_bar_height`），图标 20dp / 24dp。
- 卡片圆角 8dp；标签高 24dp 全圆；按钮高 40dp、圆角 15dp（半圆）。
- 首页 **3 列**，封面约 128dp 宽、2:3，标题 15sp、标签 12sp；一屏 6–9 本。
- 分类 3 列；详情为全出血头图，米色卡叠压其上（约占 1/3 屏）。
- 章节目录：全屏版行高约 **54dp**（缩略图约 54×36dp + 话名 + 日期/点赞）；阅读器侧栏版行高 48dp、**只有话号**，面板宽约 **275dp（62% 屏宽）**。
- 设置：行高 48–56dp，分段 chip 高 28dp，开关约 36×20dp；无分组卡、无圆角、无"确定"。
- 页边距统一 16dp；分割线 1dp #E2E2E2。
- 右下悬浮圆钮 32–40dp，1dp 描边 + 白底。

### 哔哩哔哩漫画

- 抽屉圆角 **20dp** + 32×4dp 拖拽把手；卡片圆角 **12dp**；封面 12dp（首页）/ 8dp（三列）。
- 首页 **2 列**：封面约 194dp 宽，gutter 14–16dp，标题 16sp、品类 12–13sp，右上 ⋮。
- 分类 3 列，封面约 128dp；筛选 **4 列** chip，chip 高约 28dp，全圆角，底部"重置/确认"双按钮。
- 详情：hero 全出血（约占 1/3 屏）；追漫 pill 约 78×42dp；底部固定栏 **61dp**；最近话 chip 约 36×36dp；续看 pill 高 32dp。
- 章节抽屉：行高 **72dp**，缩略图 66×44dp / 4dp 圆角，主行 16sp，元信息 12sp；右下 48dp 升降序 FAB。
- 设置：卡间距 16dp、卡内边距 16dp、行高约 56dp；分段按钮约 60×30dp；开关约 34×20dp；选中态 1dp #32AAFF 描边 + 蓝字。
- 阅读器底栏：一块约 **430×162dp** 的深色悬浮卡（左右各留 12dp），圆角 20dp，三行结构。

## 4. 分屏结构与版式

### 腾讯动漫

1. **首页**：频道 tab（可横滑，选中加粗）→ 搜索 pill + 游戏/抽赏 → 大 banner（8dp 圆角）→ 6 个 icon 快捷入口（排行/分类/完结/签到/活动/福利）→ 分区标题 + 3 列网格 → "更多 / 换一批"两枚半宽 pill。
2. **分类**：顶部多行标签墙 → "最新" + 筛选 chip → 3 列封面。
3. **详情**：全出血头图 → 米色烫金卡（标题、徽章、9.1 评分、简介、作者）→ 连载状态 → 横向话名 tab → 3 个章节卡 → 运营卡（解锁、C位推荐、月票榜）→ 话题讨论 → 底部三入口 + 金色"开始阅读"。
4. **目录（全屏）**：`目录` 居中 + X；`全部章节(681)` + `正序 | 倒序`；卷分组卡（`陨落的天才 1-20话`）→ 54dp 行（缩略图、话号、日期、点赞）；右下"到底"圆钮。
5. **目录（阅读器侧栏）**：从右侧滑出 275dp 面板，头带 `共681话 连载中 | 倒序`，行内只有 `1 - 01`，当前话橙色 pin；右下定位/下载两枚悬浮圆钮。
6. **阅读器（翻页）**：52dp 白顶栏（返回、`第1话 2/36`、收藏、评论、分享）+ 底栏（弹幕输入 pill + 目录/进度/夜间/设置四个 icon-tab，约 112dp）。
7. **阅读器（滚动）**：只保留底部一行的进度条 + `开启自动阅读`，不遮画面；页面左下浮"弹幕 2.5万"胶囊。
8. **设置**：白色整面板，自上而下：亮度滑杆 → 阅读模式 3 段 → 横竖屏 2 段 → 清晰度 3 段 → 自动阅读开关 → 显示单话评论开关（带说明）→ 显示页码开关。分层只靠 16dp 留白。

### 哔哩哔哩漫画

1. **首页**：签到胶囊 + 搜索 pill + 排行/分类 → 一级 tab（选中变大加粗）→ 登录 banner → hero 大图 + 标题/品类 chip/一句简介 → 2 列封面网格 → 底栏（首页/商城/书架/我的）。
2. **分类**：漫画/OC/小说 + 三个下拉（分类题材、地区·付费·连载、人气推荐排序）→ 三列封面；筛选为独立抽屉，chip 四列网格，底部 重置/确认。
3. **详情**：hero 轮播 + 追漫 pill → 标题 24sp → 热度/人气/评论 chips → 标签 chips → 简介三行 + 查看详情 → 连载状态 → 运营标签 → 社区/推荐/周边 pill tabs → 投喂/星光 → 评分卡 → 讨论区入口 → 系列作品横滑 → 底部固定栏（目录 + 001–004 + 续看）。
4. **章节抽屉**：20dp 圆角 + 把手 + 粉色气泡提示；`全部章节(1293)` + `列表模式`；72dp 行（缩略图、话名、日期、评论、点赞），当前话蓝 pin；右下升序/降序 FAB。
5. **阅读器**：顶部渐变 scrim（返回、话名、详情、⋮）；底部深色悬浮卡三行：评论输入 / 进度滑杆 + 上下话 + 旋转 / 设置、自动阅读（页码 1999）、目录；左侧常驻"追漫"胶囊。
6. **手势引导**：三分区虚线 + 插画（下一页/工具栏/上一页）+ "知道了"。
7. **设置**：深色抽屉，4 张卡：亮度；阅读模式 3 段（禁用态带斜杠）+ 全部生效开关 + 说明；画质 3 段 + 横竖屏 2 段（带图标）；3 个开关（其中一个带说明）。即时生效，无确定键。
8. **书架**：书架/历史/缓存 + 漫画/分组/漫单/小说 + 综合排序；未登录空态 = 淡化的 TV 吉祥物 + 一句话 + 蓝色"账号登录"。
9. **我的**：登录卡、资产/漫币、会员 banner、8 宫格入口、福利中心卡。
10. **商城**：搜索、排行榜/今日上新、魔力赏、IP 广场、商品 2 列卡片。

## 5. 交互优势（逐条）

### 腾讯

1. **密度**：3 列首页 + 54dp 目录行 + 纯话号侧栏，同屏信息量比 Bili 高约 50%，适合"找话/追更"。
2. **双形态目录**：全屏详细版给决策（缩略图、日期、点赞、卷组），阅读器侧栏版给跳转（只有话号），互不拖累。
3. **阅读器按模式换 chrome**：翻页模式给评论 + 4 个工具入口；滚动模式只留进度 + 自动阅读，遮挡最小。
4. **设置面板"一行一控"**：标签左、控件右、控件宽度统一，所有状态一眼扫完；无"确定"，改完即走。
5. **详情页 IP 化陈列**：米色烫金 + 角花 + 棕色标题 + 徽章，把作品当商品；运营卡（解锁/C位/月票）直接服务转化。
6. **首页快速翻找**："更多 / 换一批"双 pill，比下拉刷新更明确。
7. **弹幕叠加在阅读上**：左下弹幕胶囊 + 单话评论页，社区不打断翻页。

### 哔哩哔哩

1. **双色分工**：粉=品牌/运营，蓝=功能/选中，用户不会把营销色误读为状态色。
2. **工具层恒暗**：设置与目录都是深色抽屉 + 页面压暗，和漫画画面明确分层，夜间也不刺眼。
3. **抽屉语汇完整**：20dp 圆角、拖拽把手、16dp 间距、分组卡；设置即时生效。
4. **禁用态保留**：不可用模式不隐藏，加斜杠 + 降透明度；新功能用红点，用户知道"有但不可用/有更新"。
5. **章节抽屉信息足**：缩略图 + 日期 + 评论 + 点赞 + 当前话 pin + 列表模式 + 升降序 FAB，都在拇指区。
6. **首次使用教学**：三区虚线 + 手势插画 + 知道了，一次讲清点击分区。
7. **chrome 可完全隐藏**：悬浮卡不占版面；页码胶囊给进度感；追漫 pill 常驻可直接收藏。
8. **详情页社区化**：投喂/评分/讨论/系列折叠进一页，用 pill tabs 组织，不打乱主 CTA。
9. **空态与个人页成体系**：淡化吉祥物 + 一句话 + 蓝色主按钮；我的页 8 宫格 + 福利中心。
10. **字号更大、字重更强**：16sp 主 tab、20–24sp 标题，远看也清楚。

## 7. 可直接借到 NowenReader 的点（不抄版式）

1. **设置面板结构**：Bili 的 4 组卡 + 16dp 间距 + 20dp 顶圆角 + 拖拽把手；组内行高 48–56dp。
2. **行内布局**：腾讯的"标签左、控件右、所有控件右对齐同宽"；单值项（亮度、音量）用一根滑杆，不做弹窗。
3. **选中态**：1dp 主色描边 + 主色文字（Bili）；禁用项保留 + 降透明度/斜杠，不直接消失。
4. **章节列表**：Bili 的当前话 pin + 升降序 FAB + 行内元数据；行高按我们密度取 56–64dp，缩略图 4dp 圆角。
5. **阅读器底栏**：腾讯滚动模式的克制（进度 + 自动阅读）+ Bili 的页码胶囊；工具入口不超过 4 个。
6. **详情页**：追漫/收藏做成贴图悬浮 pill（Bili）；章节最近 3–4 话 + 续看固定在底栏。
7. **不要抄**：三列/两列版式、IP 烫金皮肤、粉蓝双色体系、红点角标堆叠——这些是它们的品牌资产，不是通用规则。
